# 手轮板引脚分配

ESP32-S3 N16R8（ESP32-S3-WROOM-1-N16R8）。屏幕已经接好，下面其余信号按这块屏幕让开。

公共接线：编码器、波段开关、按键的公共端都接 GND。这些脚打开内部上拉，选中或按下时为低电平。信号必须是 3.3 V，编码器如果是 5 V 输出，要先做电平转换。

## 已接线：2 寸 ST7789

模块丝印写 SCL/SDA，实际是 SPI，不是 I2C。不需要 MISO。

| 信号 | GPIO | 方向 | 说明 |
| --- | --- | --- | --- |
| SCL / SCLK | 12 | 输出 | SPI 时钟 |
| SDA / MOSI | 11 | 输出 | SPI 数据 |
| DC | 9 | 输出 | 数据/命令 |
| CS | 10 | 输出 | 片选，低有效 |
| BL | 21 | 输出 | 背光。多数模块高电平点亮 |
| RST | 14 | 输出 | 复位，低有效 |

## 待接：100 PPR 手摇编码器

| 信号 | GPIO | 方向 | 说明 |
| --- | --- | --- | --- |
| A | 4 | 输入，上拉 | 编码器 A 相 |
| B | 5 | 输入，上拉 | 编码器 B 相 |

## 待接：急停

用常闭触点。触点接在 GPIO1 和 GND 之间，内部上拉。

| 状态 | 电平 |
| --- | --- |
| 正常，触点闭合 | 低 |
| 急停按下，或导线断开 | 高 |

断线会和按下一样被当成急停。

## 不要占用

| GPIO | 原因 |
| --- | --- |
| 19、20 | 原生 USB。下载和日志走这里 |
| 43、44 | 留给 UART0 调试口，TX=43，RX=44，115200 |
| 0、3、45、46 | 启动配置脚。0 是 BOOT |
| 26–34 | 模块内部 Flash，管脚没有引出来 |
| 35、36、37 | N16R8 的八线 PSRAM，不能外接 |
| 33、34 | 模块上没有引出，八线存储器在用 |

## 板载 RGB 状态灯

DevKitC-1 上的那颗灯接 GPIO48，WS2812，不用再接线。

| 颜色 | 含义 |
| --- | --- |
| 红，闪 | 没连上另一块板 |
| 黄，常亮 | 两块板已连接，Mach3 还没送来坐标 |
| 绿，常亮 | 正在收到 Mach3 坐标 |
